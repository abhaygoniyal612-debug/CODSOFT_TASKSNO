# CODSOFT Python Internship - Task 3

## Password Generator

This project is developed as part of the **CodSoft Python Programming Internship**.

The Password Generator is a Python-based application that generates strong and random passwords according to the length specified by the user. It uses a combination of letters, numbers, and special characters to create secure passwords.

## Features

- User can specify the password length
- Generates random passwords
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Creates different passwords randomly
- Simple and user-friendly interface

## Technologies Used

- Python
- Jupyter Notebook
- `random` module
- `string` module

## How to Run

1. Download or clone this repository.
2. Open `Task3_PasswordGenerator.ipynb` in Jupyter Notebook.
3. Run all the cells in order.
4. Enter the desired password length.
5. The program will generate and display a random password.
