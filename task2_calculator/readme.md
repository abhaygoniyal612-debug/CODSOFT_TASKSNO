# CODSOFT Python Internship - Task 2

## Calculator

This project is developed as part of the **CodSoft Python Programming Internship**.

The Calculator is a simple Python-based application that performs basic arithmetic operations. It takes two numbers and an operation from the user and displays the calculated result.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Handles division by zero
- Handles invalid number input
- Simple and user-friendly interface

## Technologies Used

- Python
- Jupyter Notebook

## How to Run

1. Download or clone this repository.
2. Open `Task2_Calculator.ipynb` in Jupyter Notebook.
3. Run all the cells in order.
4. Enter two numbers when prompted.
5. Select the desired arithmetic operation.
6. The calculator will display the result.

```text
+  Addition
-  Subtraction
*  Multiplication
