# CODSOFT Python Internship - Task 1

## To-Do List Application

This project is developed as part of the **CodSoft Python Programming Internship**.

The To-Do List application is a simple Python-based application that helps users manage their daily tasks efficiently. Users can add, view, update, complete, and delete tasks through a simple menu-driven interface.

## Features

- Add a new task
- View all tasks
- Update an existing task
- Mark a task as completed
- Delete a task
- Simple and user-friendly menu
- Handles invalid inputs

## Technologies Used

- Python
- Jupyter Notebook

## How to Run

1. Download or clone this repository.
2. Open the `Task1_ToDo_List.ipynb` file in Jupyter Notebook.
3. Run all the cells in order.
4. Use the menu displayed by the program to manage your tasks.
